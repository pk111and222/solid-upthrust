## 回归操作定义

1. **核对用户能力与导出**：逐个核对源码 Props、主入口、子路径和真实调用方；区分公开 API 与内部复用能力，不以新增导出数量作为完成条件。
2. **源码与演示回归**：检查默认态 → 交互 → 响应式更新 → 清理；在 example 和文档产物上检查实际绘制与交互。
3. **文档交付**：用途、导入、全部 Props、默认值、事件、样式优先级及限制；文档通过 `?raw` 展示同一份可运行示例。
4. **用例补全**：每条用例上方写中文备注，标题含能力 ID；覆盖每个 Props 的分支及会改变 DOM 的风险组合，不做无意义的全部笛卡尔积。DOM 层不能代替浏览器绘制验证。

## 契约与必要性

- ConfigProvider：应用局部统一默认属性与配色，保留公开 `ConfigProvider/useConfig/useComponentProps` 及已有五个配置类型。props 优先级、Form 默认值、嵌套合并、inherit=false、theme/prefix、class/style、children、弹层和响应式行为见文档。没有 locale/RTL 或静态全局 setter。
- Icon：必要的通用展示组件，保留 `Icon/IconProps/toIconClass`。所有 size/color 分支、spin/rotate/style、class、name、点击与更新移除均测试。静态 mdi 简写原先漏提取 CSS，先用失败测试复现后修复。动态名称仍需 safelist；spin 的 transform 动画优先于静态 rotate，不自动提供按钮键盘语义。
- _VirtualList：Select、TreeSelect、Cascader 依赖的固定行高内部组件，保留子路径与 `VirtualListProps`，不增加顶层公开导出。逻辑层 `createVirtualList/VirtualListConfig` 已导出。覆盖 items/virtual/height/itemHeight/activeIndex/class/role/children，以及逻辑层 overscan、scrollToIndex、setScrollTop 的边界。
- B08 前置：已运行现有 `headless/ColorPicker/colorPicker.test.ts` 的 23 条用例；另补颜色到主题变量的 C01 专项。仅验证 C01 所需颜色解析，不宣称 B08 ColorPicker 整体回归完成。
- 版本：Node 22.22.0、pnpm 11.16.0、solid-js 与 @solidjs/web 2.0.0-rc.0、Vitest 4.1.10、Playwright 1.63.0；未升级依赖。
